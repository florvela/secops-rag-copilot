# ISO 27001 Control Violation Response
Respond to an information-security control violation: unauthorized access to sensitive information, policy breaches, or audit findings. Record the violation and drive corrective action.

# Triage
- Enrich the event with the control affected, the asset, and the user or system involved.
- Review the compliance-violation history to judge whether it is isolated or recurring.

# Containment
- Stop the ongoing violation (revoke the access or block the action that breached the control).
- Preserve records needed for the compliance case.

# Notification and closure
- For severe violations, notify the CISO; always notify the compliance team.
- Open a compliance ticket, start corrective action, and close once the control is restored.
